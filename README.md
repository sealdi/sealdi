# Base de datos simple con SQLite

Este repositorio incluye un script en Python que crea una base de datos SQLite llamada `tienda.db` con tablas de clientes, productos y pedidos, además de insertar algunos datos de ejemplo.

## Requisitos

- Python 3.9 o superior (viene con el módulo estándar `sqlite3`).

## Uso

1. Ejecuta el script:

   ```bash
   python create_db.py
   ```

2. Se generará el archivo `tienda.db` en el mismo directorio y se mostrarán los datos insertados por consola.

Puedes abrir la base de datos con cualquier herramienta compatible con SQLite para explorar las tablas `clientes`, `productos` y `pedidos`.
